## 2. 🛡️ Formulário de Segurança dos Dados (Data Safety)

**Onde ir no Console:**  
`Menu Lateral` → `Conteúdo do App` (ou `App Content`) → `Segurança dos dados`

### 📋 **Respostas para Marcar:**

1. **Coleta e Compartilhamento de Dados:**
   - *"Seu app coleta ou compartilha algum dos tipos de dados de usuário qualificados?"* → **NÃO** (ou se marcar dados de saúde/uso local, marcar que o processamento é **on-device** e não compartilhado).
2. **Identificador de Publicidade (Advertising ID / AD_ID):**
   - *"Seu app usa um ID de publicidade?"* → Selecionar **NÃO**.
