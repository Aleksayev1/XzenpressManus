# 📝 Templates Tier 1 - Comentários Manuais

## 🎯 Objetivo

Templates organizados para uso manual, permitindo comentar rapidamente em vídeos virais com alta qualidade.

---

## 🗂️ Como Usar

1. Identificar vídeo viral relevante
2. Escolher template adequado ao contexto
3. Copiar e colar (ou adaptar levemente)
4. Postar em horário de pico

**Meta**: 20-30 comentários/semana com este método

## 🎨 Templates com Personalização

### Template Variável (Preencher Lacunas)

**Para Ansiedade:**
```
"[SINTOMA] não é sinal de fraqueza, é [SEU CORPO/MENTE] pedindo ajuda.
Descobri [SOLUÇÃO XZENPRESS] e mudou tudo. [EMOJI_CONTEXTO]"

Exemplos preenchidos:
- "Coração acelerando não é sinal de fraqueza, é seu corpo pedindo ajuda.
  Descobri acupressão e mudou tudo. ❤️‍🩹"
  
- "Pensamentos em loop não é sinal de fraqueza, é sua mente pedindo ajuda.
  Descobri respiração guiada e mudou tudo. 🌬️"
```

**Para Depoimentos Pessoais:**
```
"Passei [TEMPO] sofrendo com [PROBLEMA]. [MÉTODO XZENPRESS] 
me devolveu [BENEFÍCIO]. Compartilho porque funciona. [EMOJI]"

Exemplos:
- "Passei 3 anos sofrendo com insônia. Sons binaurais 2Hz
  me devolveram noites de sono. Compartilho porque funciona. 💤"
```

## 📋 Checklist Antes de Postar

- [ ] Assisti ao vídeo completo?

- [ ] CTA é sutil?
- [ ] Revisei erros de digitação?
- [ ] Horário é de pico (18h-22h)?
