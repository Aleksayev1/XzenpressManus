# 🔗 Como Criar Atalho na Área de Trabalho

## Opção 1: Arrastar Arquivo .bat (MAIS FÁCIL) ⭐

1. Vá para a pasta do projeto XzenpressManus
2. Encontre os arquivos:
   - `ABRIR_MARKETING_MATRIX.bat`
   - `ABRIR_ATALHOS_TRABALHO.bat`
3. **Arraste** qualquer um deles para sua **Área de Trabalho**
4. Pronto! Clique duas vezes para abrir

---

## Opção 2: Criar Atalho Manualmente

### Para a Pasta Marketing_Matrix:

1. Clique com botão direito na **Área de Trabalho**
2. Escolha: **Novo > Atalho**
3. Cole este caminho:
   ```
   C:\Users\Alexandre\.gemini\antigravity\scratch\XzenpressManus\Marketing_Matrix
   ```
4. Clique em **Avançar**
5. Nome sugerido: `Marketing Matrix`
6. Clique em **Concluir**

### Para o Arquivo ATALHOS_TRABALHO.md:

1. Clique com botão direito na **Área de Trabalho**
2. Escolha: **Novo > Atalho**
3. Cole este caminho:
   ```
   C:\Users\Alexandre\.gemini\antigravity\scratch\XzenpressManus\Marketing_Matrix\ATALHOS_TRABALHO.md
   ```
4. Clique em **Avançar**
5. Nome sugerido: `Atalhos XZenPress`
6. Clique em **Concluir**

---

## Opção 3: Pin na Barra de Ferramentas (Quick Access)

1. Abra o **Explorador de Arquivos**
2. Navegue até:
   ```
   C:\Users\Alexandre\.gemini\antigravity\scratch\XzenpressManus\Marketing_Matrix
   ```
3. Clique com botão direito na pasta `Marketing_Matrix`
4. Escolha: **Fixar no Acesso Rápido**
5. Agora aparece no menu lateral esquerdo sempre!

---

## 🎯 Recomendação

Use a **Opção 1** - é só arrastar o arquivo `.bat` e pronto! 😊
