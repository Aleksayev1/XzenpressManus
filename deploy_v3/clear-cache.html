🔄 Limpeza de Cache XZenPress

Se você está tendo problemas para acessar o site, esta página vai limpar todo o cache e dados antigos.

Limpando cache...

📋 Se o problema persistir, limpe manualmente:

  1. Chrome/Edge: Ctrl+Shift+Del → Selecione "Cookies" e "Imagens e arquivos em cache" → Limpar dados
  2. Firefox: Ctrl+Shift+Del → Selecione "Cookies" e "Cache" → Limpar agora
  3. Safari: Cmd+Option+E → Limpar histórico
  4. Após limpar: Feche TODAS as abas do XZenPress e reabra

💡 Dica: Use Ctrl+F5 (Windows) ou Cmd+Shift+R (Mac) para recarregar sem cache
